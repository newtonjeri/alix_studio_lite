2. Processing parameters

Defaults match the trajectory algorithm used previously.
Processing stages to apply
Select any one stage or any combination. When multiple stages are enabled, they are always applied in this order: Trim → Mean Smooth → Scale. Unchecked stages are skipped completely.
Algorithm used

Idle trim: calculate absolute change between consecutive rows for each joint, apply a centered rolling mean, mark a step idle only when all 7 joints are at or below the threshold, require the condition to persist for the minimum run, then keep the first and last point of each idle block and remove the interior points.

Mean smoothing: centered moving mean (default 101 points), then recenter each joint so its overall trimmed mean is preserved; exact first and last joint positions are restored.

Region scaling: synchronized linear interpolation across all 7 joints. 100% = unchanged duration, 150% = 50% longer/slower, 50% = half as many intervals/faster, 30% = 30% of the original region duration.

3. Automatic speed optimization analysis

Section B1/B2 - motion analysis and region-based recommendations
After a trajectory is loaded, the browser automatically analyzes joint-motion intensity, direction-change activity and peak motion. It divides the trajectory into review regions and suggests whether each region should be shorter/faster, longer/slower or unchanged.
Important: The uploaded trajectory contains joint positions only. The browser can identify motion patterns, but it cannot prove physical cleaning contact or collision safety without force/contact and simulation data. Smooth continuous regions are therefore marked as possible cleaning/straight-pass candidates for operator review.
